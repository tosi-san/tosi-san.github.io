# tosi-san.github.io
あったらいいな。 あるっていいな。 高齢者の目に優しい特大までのフォントサイズのレースアシスタンス。 市民大会プールサイドで役員不足をアシスタンス。エントリー・種目・大会記録から、組み分け・プログラム・競技速報・得点まで自動で連動します。 漏洩防止、外部通信（ネット接続）:遮断。 edge・chromeで完全ローカル運用。これまでの見づらい分かりづらいから見やすい分かりやすい表形式表示に。エントリーはCSV/表（Word、メモ帳、Excel、LibreOffice、等）形式で提出してもらえればコピペで組み分け（10レーンまで任意のレーン数で設定）まで一括登録できます。大会記録/水中スタート大会記録、大会新記録、開始予定時間、再レース、合同レース、審判用紙、等々連動します。メインプログラムではありませんが汎用性でメインプログラム代用できます。
